Polar NRZ

1 = +1 V; 0 = −1 V. Each level lasts one full bit time.

Polar RZ — 50% duty cycle

1 = +1 V then 0 V; 0 = −1 V then 0 V. Each pulse occupies half a bit time.

Manchester

Convention used: 1 = high-to-low; 0 = low-to-high. Every bit has a transition at its midpoint.

Frequency spectrum

FFT of the displayed finite sequence, zero-padded to 4096 samples. Magnitude is |FFT| divided by the number of signal samples. This is a magnitude spectrum, not power spectral density. Increasing bit rate shortens each bit and moves the spectrum toward higher frequencies. Manchester guarantees a midpoint transition, which supports clock recovery.

Try this: Select “All ones,” then compare the transitions. Next, double the bit rate and observe the time values and bandwidth markers.

Model limitation: ideal rectangular pulses with instantaneous edges; no noise, attenuation, or channel filtering. Their spectra extend indefinitely. First-null bandwidth describes the main spectral lobe, not a strict frequency cutoff or minimum channel bandwidth.
